# Abollism

ویترین کارهای شخصی + تریبون + چت محدود (فقط با دعوت‌نامه).

## راه‌اندازی

1. در [Supabase](https://supabase.com) یک پروژه جدید بساز.
2. در **SQL Editor** به ترتیب این دو فایل را اجرا کن:
   - `supabase/schema.sql`
   - `supabase/schema2.sql`
3. در Authentication → Providers → Email:
   - گزینه **Confirm email** را خاموش کن.
4. `.env.example` را به `.env.local` کپی کن و مقادیر را پر کن:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   ```
5. نصب و اجرا:
   ```bash
   npm install
   npm run dev
   ```
6. **قبل از اینکه آدرس را به کسی بدهی**، خودت یک‌بار در `/login` ثبت‌نام کن.  
   اولین حساب بدون کد دعوت ساخته می‌شود و خودکار ادمین می‌شود. بعد از آن همه نیاز به کد دعوت دارند.

## مسیرها

| مسیر       | توضیح                          |
|------------|--------------------------------|
| `/`        | صفحه اصلی (ویترین + آخرین نوشته‌ها) |
| `/blog`    | لیست نوشته‌ها                  |
| `/blog/[slug]` | یک نوشته + نظرات + ری‌اکشن |
| `/chat`    | چت (DM / گروه / کانال) — فقط کاربران واردشده |
| `/login`   | ورود/ثبت‌نام با کد دعوت      |
| `/admin`   | پنل مدیریت (فقط ادمین)         |

## نکات امنیتی

- همه جداول مهم Row Level Security دارند.
- ثبت‌نام فقط با کد دعوت (بعد از اولین کاربر).
- پیام‌های چت plaintext ذخیره می‌شوند (E2EE ندارد).
- این پروژه برای جمع کوچک و مورد اعتماد طراحی شده، نه پیام‌رسان عمومی.
